{% comment %} Experience is drawn as a branching graph. Time runs left to right in columns, one per distinct end date (no `end` = present, the last column), so a card sits where its position ended and positions ending together stack in the same column. Rows are lanes: row 0 is the main line. Back-to-back roles at the same company (the next one starting at most a month after the previous ended: a promotion) form a chain that shares one lane. Chains are walked by start date, the longer running first when they start together, and each takes the first lane that's free by then (its last chain ended in or before the start month). So a chain that starts while the main line is busy forks off it as a branch, in the gap before the first column it was running at, and later roles in a chain carry on from the previous card's node.
