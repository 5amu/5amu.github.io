Skills I use with coding agents. Each one is a single `SKILL.md` file of instructions the agent loads when a task matches its description. The [`skills` CLI](https://github.com/vercel-labs/skills) installs them into Claude Code, Codex, Cursor, OpenCode and the other agents it supports, and asks which ones and where.
